    Frequently asked questions

    Which file formats are supported?

    Merge: .xlsx, .xlsm, .xls and .csv. Compress: .xlsx and .xlsm. ZIP: anything you can upload (up to 30 files, 100 MB per request).

    Will merging lose my formatting or formulas?

    Merge mode is value-based: it combines the cell values (including computed formula results) into a clean report — like copy-pasting data. "Each file = one sheet" keeps each file's layout intact. Formatting is intentionally not copied so the output is one consistent, clean table.

    What does the compressor actually remove?

    Safe: re-encodes embedded images (JPEG quality / PNG optimization), removes the document thumbnail and calc chain, and repacks the ZIP at maximum compression. Maximum: also strips conditional formatting, data validations and completely empty sheets. Cell data, formulas, charts and styles are always preserved.

    How long are my files kept?

    Results are available for download for 1 hour, then automatically deleted. Uploaded files are deleted immediately after processing.
